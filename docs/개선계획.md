## 3. 디자인 방향 (확정된 것 / 남은 결정)

### 3-1. 결정된 것
- **글꼴: SUIT** (앱 내장, 오프라인에서도 동일) — 적용 완료(`design/font-suit` 브랜치)
- **모서리: 살짝 둥글게(2차 시안 B안)** — 기존 "각진 형태" 결정을 변경(2026-10-28). 카드·큰 버튼 16px, 작은 버튼·칩·썸네일 10px, 가운데 「물건 적기」 버튼은 원형. `index.css`의 `border-radius: 0 !important` 전역 규칙은 4단계(디자인 적용)에서 제거
- **색으로 설명하지 않기**: "주황은 사진·초록은 가게·보라는 장부", 탭 아래 「파랑/초록/보라」 삭제
- **2차 시안 방향**: 1차 시안(단색·테두리 위주)은 "효도폰 같다"는 의견으로 폐기
  - 남색(정보·합계) + 주황(적기·저장) **두 색**만 사용
  - 그림자 카드, 남색 합계 카드 + 영수증 톱니 마감, 이번 주 막대그래프
  - 하단 메뉴 가운데 「물건 적기」 돌출 버튼, 입력 화면 단계 표시
  - 장부는 달력(날짜별 금액) + 날짜 누르면 그날 기록
- **참고 앱**: 분위기 토스 · 홈 캐시노트 · 적는 흐름 당근 · 장부 편한가계부

## 5. 화면별 구성 (2차 시안 기준)

**홈**: 날짜·설정 → 남색 「오늘 쓴 돈」 카드(고민 중 별도 표시, 이번 달 합계) → 이번 주 그래프 → 오늘 적은 것(최근 기록, 누르면 상세) → 하단 메뉴. 가게 순위·종류별 통계는 장부/통계로 이동.

**물건 적기**: 단계 표시 → 사진(선택) → 가게(없으면 같은 자리에서 이름만 적어 추가) → 한 개 가격(쉼표 표시, +1천/+5천/+1만) → 몇 개(−/+, 직접 입력) → 합계 카드 → 「더 적기」(날짜·상태·종류·색·크기·이름·메모) → 「○○원 저장하기」. 저장 후 결과 화면.

**장부**: ◀ 월 ▶ → 그 달 쓴 돈 카드 → 달력/목록 전환 → 날짜 누르면 그날 기록 → 「엑셀로 받기·백업하기」는 맨 아래. 검색·가게·종류·상태 조건은 「찾기」 안에. 조건이 걸리면 "10월 · 미소옷장" 표시 + 해제 버튼.

**기록 상세(신규)**: 사진 크게(여러 장 넘기기) → 내용 → 「고치기」(주) / 「지우기」(아래, 확인창에 이름·금액 표시).

**가게**: 목록(이름·위치·이번 달 금액) → 상세(「전화 걸기」「이 가게 물건 적기」, 정보 18px, 「가게 숨기기」 맨 아래).

**설정**: 다른 폰과 같이 쓰기 상태 한 문장 + 마지막 맞춘 시간 → 백업하기 / 백업에서 되살리기(되살리기 전 날짜·건수 미리 보기) → 글씨 크기(보통/크게/아주 크게) → 고급(사진 선명도, 저장 공간, 모든 기록 지우기).

## 7. 어르신 사용자 테스트 (Codex 제안 채택)

70대·80대 5~8명. 평소 안경·글자 설정 그대로, 사용법을 먼저 알려 주지 않고 과제만 드림.

1. 사진 없이, 어제 미소옷장에서 15,000원짜리 니트 3개 산 기록 남기기
2. 잘못 적은 15,000원을 18,000원으로 고치고 합계 54,000원 확인하기
3. 지난달 특정 가게 기록 찾고 다시 홈으로 돌아오기
4. 사진 3장 붙이고 잘못 붙인 마지막 사진 바꾸기
5. 아직 안 산 옷을 적고, 쓴 돈에 안 들어간다는 걸 이해하기
6. 기록을 백업하고 다른 기기에서 되살리기
7. 적는 도중 전화가 온 뒤 돌아와 계속 적기 / 인터넷이 끊긴 상태에서 저장하기

목표: 등록·수정 과제 혼자 완료 90% 이상, 돈·사진·기록 손실 0건, 중복 저장 0건.
