## 2. 버그 · 미구현 기능 (먼저 고칠 것)

### P0 — 데이터가 틀어지거나 사라질 수 있는 문제

**2-1. 「모든 기록 지우기」 후 예시 데이터가 다시 생김** *(실제 재현함)*
- 원인: `src/db/seed.js` — 가게가 0개면 앱 켤 때마다 예시 가게·기록(미소옷장 등)을 넣음.
- 영향: 실제 사용자에게 처음부터 가짜 가게·가짜 금액(오늘 229,000원 등)이 보임. 지워도 다시 생김.
- 조치: 예시 데이터는 개발 모드(`import.meta.env.DEV`)에서만 넣거나, "처음 한 번만" 표시(localStorage 플래그). 실사용자에겐 빈 화면 + 첫 사용 안내.

**2-2. 새 폰에서 초대 링크로 연결하면 예시 데이터가 공유 장부에 올라감**
- 원인: 앱 시작 시 시드 → `/join` → `syncBidirectional()`이 로컬 전체를 먼저 푸시.
- 조치: 2-1 해결로 대부분 해소. 추가로 연결 시 "이 폰 기록을 올릴지" 확인.

**2-3. 삭제가 다른 폰에 반영되지 않음(지운 게 되살아남)**
- 원인: `deleteShop`/`deleteItem`은 로컬만 지우고, 클라우드 `deleted_at`을 표시하지 않음 → 다음 동기화 때 다시 내려옴.
- 조치: 삭제 시 클라우드 행에 `deleted_at` 기록, 로컬에도 삭제 표시(soft delete) 후 동기화.

**2-4. 다른 폰에서 고친 내용이 덮어써짐**
- 원인: `pushLocalToCloud()`가 저장할 때마다 **모든** 가게·기록을 로컬 값으로 덮어씀(변경 여부·시간 비교 없음). 기록이 많아지면 저장이 점점 느려짐.
- 조치: 로컬에 `updatedAt` 저장 → 바뀐 것만 올리고, 더 최신인 쪽을 남기기.

**2-5. 「검토」「보류」도 '쓴 돈'에 합산됨**
- 원인: `summarizeItems()`가 상태 구분 없이 합산. 홈 「오늘 쓴 돈」, 월 합계, 장부 합계 전부 해당.
- 조치: 합계는 「구매」만, 검토·보류는 "아직 안 산 것 ○개"로 따로 표시.

### P0~P1 — 있어야 하는데 없는 기능

**2-6. 기록 수정·삭제 화면이 없음**
- `updateItem`, `deleteItem` 함수는 만들어져 있지만 어떤 화면에서도 쓰지 않음. 장부·홈·가게 상세의 기록 줄은 눌러도 반응 없음.
- 조치: 기록 상세 화면 `/items/:id` 추가 → 사진 크게 보기, 고치기, 지우기(확인창).

**2-7. 날짜를 바꿔 적을 수 없음**
- 저장 시 항상 `getToday()`. 어제 산 것을 오늘 적으면 날짜가 틀어짐(가계부로서 치명적).
- 조치: 등록 화면에 「오늘 / 어제 / 날짜 고르기」 버튼.

**2-8. 가게 전화번호를 눌러도 전화가 안 걸림**
- 조치: `tel:` 링크 + 「전화 걸기」 큰 버튼.

**2-9. 가게 상세에서 바로 "이 가게로 적기" 불가**
- 조치: 가게 상세에 「이 가게 물건 적기」 버튼 → `/capture`에 가게 선택된 채로 이동.

**2-10. 사진 없이는 적을 수 없음**
- 사진을 넣어야 입력 칸이 나타남. 사진 못 찍은 거래(현금 지출, 택배비 등)를 못 적음.
- 조치: 「사진 없이 적기」 버튼.

## 3. 디자인 개선 계획

### 3-1. 현재 문제 요약
1. **색으로 설명함** — "주황은 사진 · 초록은 가게 · 보라는 장부", 하단 탭 아래 「파랑/초록/보라」 글자. 어르신은 색 이름을 외우지 않고, 색약·노안이면 구분도 어려움. 색은 보조여야 하고 **말과 그림이 주인공**이어야 함.
2. **색이 너무 많고 모두 강함** — 화면 하나에 파랑·주황·초록·보라·호박색 버튼이 동시에 나옴(장부 화면 파일 버튼 3개가 3가지 색). 무엇이 중요한지 오히려 흐려짐.
3. **모든 글씨가 굵음(font-black)** — 전부 강조하면 아무것도 강조되지 않음. 제목/본문/보조 위계가 없음.
4. **화면마다 디자인이 다름** — 가게 상세·가게 추가·확인창은 옛 디자인(글씨 12~13px, 얇은 선, 작은 버튼), 나머지는 새 디자인.
5. **너무 작은 글씨 잔존** — 탭 보조글 10px, 「사진」 12px, 가게 상세 라벨 12px, 확인창 13px.
6. **줄무늬 배경·그라데이션·왼쪽 색 띠** — 장식이 많아 시선이 분산됨.
7. **한 화면에 너무 많음** — 장부 화면: 합계 → 파일 버튼 3개 → 통계 → 필터 4종 → 목록. 정작 "기록 보기"는 한참 아래.

### 3-4. 화면별 개선

**공통**
- 하단 탭: 「홈 / 적기(가운데, 크게) / 장부 / 가게」 + 설정은 홈 오른쪽 위로. 떠 있는 사진 버튼(FAB) 제거 → 가운데 탭으로 통합. 탭 보조글(파랑 등) 삭제.
- 모든 화면 상단에 **뒤로가기 큰 버튼**(「← 뒤로」 글자 포함) 통일. 가게 상세/추가도 하단 탭 표시.
- 확인창(`ConfirmDialog`, `ImportModeDialog`) 새 디자인 적용: 글씨 18px, 버튼 56px, 위험 버튼은 오른쪽 아래·빨강, "취소"가 기본.
- 저장/삭제 후 3초간 화면 위쪽 **큰 알림띠**("저장했어요 ✓") 통일.

**홈**
- 색 설명 문구 삭제.
- 「오늘 쓴 돈」 한 칸을 크게(금액 32px), 「이번 달」은 그 아래 한 줄로.
- 큰 버튼 하나: 「📷 물건 적기」.
- 「오늘 적은 것」 목록은 최근 3개만 + 「장부에서 모두 보기」.
- 「이번 달 많이 간 가게」「옷 종류별」은 장부 화면으로 이동(홈은 단순하게).
- 처음 사용자(기록 0개)에겐 3단계 그림 안내: ① 사진 찍기 → ② 가게 고르기 → ③ 가격 적고 저장.

**사진 적기(등록)** — 가장 중요한 화면
- 4개 묶음(가게/이름·가격/종류·상태/색·크기)을 **필수만 위에**: 가게 → 가격 → 몇 개 → 이름(선택) → 「더 적기 ▾」(종류·상태·색·크기·메모·날짜)로 접기.
- 가격 입력: 숫자 키패드 + **「천원」「만원」 빠른 버튼**, 입력 중 「15,000원」처럼 쉼표 표시, 바로 아래 "합계 45,000원(15,000원 × 3개)" 실시간 표시.
- 몇 개: 「− 1 +」 큰 버튼으로 통일(현재 프리셋 4개 + 드롭다운 중복 제거).
- 상태: 드롭다운 대신 큰 버튼 3개 「샀어요 / 고민 중 / 안 사요」.
- 날짜: 「오늘」 기본, 「어제」「날짜 고르기」.
- 저장 버튼 비활성 시 "아직이에요"만 쓰지 말고 **빠진 칸을 빨간 테두리 + 그 칸으로 스크롤**.
- 사진 미리보기 크게(화면 폭), 사진 삭제는 1장일 때도 가능.

**장부**
- 상단: 기간 선택(「이번 달 ◀ ▶」 화살표로 달 이동) + 합계.
- 목록은 **날짜별 묶음**("10월 28일 (수) · 3건 · 229,000원").
- 줄을 누르면 기록 상세(수정/삭제).
- 필터는 「찾기」 버튼 하나로 접어 두기(검색·가게·종류·상태).
- 엑셀/백업 버튼 3개는 화면 맨 아래 「파일로 저장·불러오기」 한 묶음으로 이동, 같은 색.
- 가게별·종류별 합계는 「통계 보기」 탭으로.

**가게**
- 목록: 가게 이름 크게 + 「청평화 3층 A-123」 한 줄 + 이번 달 금액.
- 상세: 「📞 전화 걸기」「📷 이 가게 물건 적기」 큰 버튼 2개, 정보 글씨 18px, 「가게 삭제」는 맨 아래 작은 글씨 링크 + 확인창.

**설정**
- 「다른 폰과 같이 쓰기」를 맨 위, 상태를 한 문장으로: "✓ 아들 폰과 같이 쓰는 중".
- 「인터넷 내용으로 채우기」처럼 위험한 버튼은 확인창 필수.
- 「사진 선명도」 슬라이더(50~95%) → 「보통 / 선명하게」 2개 버튼.
- 「글씨 크기」 설정 추가: 보통 / 크게 / 아주 크게 (html font-size 19→21→23px).

### 3-5. 문구 개선 (예시)

| 현재 | 개선안 | 이유 |
|---|---|---|
| 주황은 사진 · 초록은 가게 · 보라는 장부입니다 | (삭제) | 색 외우기 강요 |
| 가장 자주 쓰는 버튼이에요 | (삭제) | 불필요한 설명 |
| 사진 찍고 적기 | 물건 적기 | 사진 없이도 적을 수 있게 |
| 다 적었으면 저장 | 저장하기 | 짧고 명확 |
| 아직이에요 · 가게, 옷 이름(또는 메모), 가격을 채워 주세요 | 가게와 가격을 적어 주세요 | 필수 최소화 + 구체적 |
| 한 개 가격 (원) | 한 장 가격 | 의류 현장 말투 |
| 몇 개 샀나요? / 사진 장수와 다른 말이에요. 「산 개수」입니다. | 몇 장 샀어요? | 설명이 필요한 말은 바꾸는 게 맞음 |
| 구매 / 검토 / 보류 | 샀어요 / 고민 중 / 안 사요 | 한자어 → 일상어 |
| 지금 보이는 합계 | 이번 달 쓴 돈 (기간에 따라 바뀜) | 무엇의 합계인지 명시 |
| 기록 8개 · 옷 30장 | 8번 · 30장 | 짧게 |
| 엑셀로 저장하기 / 엑셀에서 가져오기 / 사진까지 통째로 보관하기 | 엑셀 파일로 받기 / 엑셀 파일 넣기 / 전체 백업하기(사진 포함) | 동작이 분명하게 |
| 지우고 덮어쓰기 / 기존에 합치기 | 지금 기록 지우고 바꾸기 / 지금 기록에 더하기 | 결과를 말로 |
| 이 장부 인터넷에 맡기기 | 다른 폰과 같이 쓰기 시작 | 목적 중심 |
| 지금 맞추기 / 인터넷 내용으로 채우기 | 지금 새로 받기 / (숨기기 또는 확인창) | 위험 동작 숨김 |
| 번호로 직접 연결 (거의 안 씀) | 초대 번호 직접 넣기 | |
| 사진을 정리하는 중… | 사진 넣는 중이에요… | |
| 삭제된 가게 / 없는 가게 / 무제 상품 / 이름 없음 | (가게 없음) / 이름 없는 물건 | 통일 |
| 데이터베이스 초기화 실패 | 앱을 여는 중 문제가 생겼어요. 다시 열어 주세요 | 전문용어 제거 |
| 엑셀 파일(.xlsx)만 불러올 수 있습니다 | 엑셀 파일만 넣을 수 있어요 | 확장자 제거 |
| 「서버 키」를 넣어 달라고 해 주세요 | 아직 준비 중이에요. 도와주시는 분께 말씀해 주세요 | |

말투 규칙: 해요체 통일, 한 문장 20자 내외, 한자어·영어·기호(「」, ·, ›) 최소화, 부정문보다 할 일을 말하기.

## 4. 가계부 기능 관련 확인이 필요한 부분

현재 앱은 **옷 사입 기록 전용**입니다. "가계부"로 쓰신다면 아래가 없습니다. 필요 여부를 정해 주시면 범위에 넣겠습니다.
- 옷 외 지출(택배비, 차비, 식비 등) 적기 — 「물건」/「그 외 지출」 구분
- 결제 방법(현금/카드/계좌), **미송·외상(아직 안 준 돈)** 표시와 합계
- 판매(수입) 기록 및 남은 돈
- 지난달과 비교("지난달보다 12만원 덜 썼어요")
